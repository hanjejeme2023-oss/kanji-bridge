## Part B — Codex: typing, global controls, カード, 音のルール

1. **Judging (D71 item 2), one shared function** used by カード, 音のルール test and 字体 quiz:
   - **Chinese:** NFD, remove tone marks (U+0304, U+0301, U+030C, U+0300), `ü`/`v`/`u:` → `ü`, casefold, remove spaces, apostrophes (`'` `’`) and hyphens; compare with the target treated the same way.
   - **Vietnamese:** NFD, remove only the five tone marks (U+0301 sắc, U+0300 huyền, U+0309 hỏi, U+0303 ngã, U+0323 nặng), NFC; Telex for letters: `aa→â`, `aw→ă`, `ee→ê`, `oo→ô`, `ow→ơ`, `uw→ư`, `dd→đ` (applied to the typed text before comparing); casefold, remove spaces; compare with the target and with every `vi_alt` (word cards) treated the same way. ă â ê ô ơ ư đ must match (a plain `a` for `â` is wrong). *Claude's reading (D71): the Telex tone keys s f r x j are not stripped or interpreted.*
   - Result: right → 「正解」 in green; wrong → red with the correct answer (with tone marks) shown. Use the prototype's existing ok/ng colours.
2. **Tone hint before typing (D71 item 2):** shown wherever a Chinese or Vietnamese answer is typed (card front, rule test, 字体 quiz cell). Chinese: per syllable 「1声」「2声」「3声」「4声」「軽声」 joined by 「・」, from `pt` (words) or the syllable's mark (single syllables). Vietnamese: per syllable `ngang` `sắc` `huyền` `hỏi` `ngã` `nặng` joined by 「・」, computed from `vi` split on spaces (the mark on the syllable, none = ngang). A word without `pt` shows no Chinese hint (expected rare; Part A reports the count).
3. **Global (D71 item 3):** Enter **and Space** advance wherever Enter advances now; inside a text input Space types a space until the answer is judged, then advances (*Claude's reading*). A global mute toggle (no speech while on; localStorage `kb_mute`). Item counts per tab (the number of items the tab currently offers under its filters). One-line tab explanation under each tab title (§4).
4. **カード (D71 items 1, 5):** the deck is **multi-character** `card_eligible` words only (**6,983**; was 8,554). Single-character words leave カード (they are in 字体, Part C); their SRS state stays in `kb_srs` untouched and unused. Custom cards from 読解 keep working for any word. The D20 daily limit and ordering are unchanged. **After the answer is shown:** the word's `card` example(s): Chinese sentence with pinyin and Japanese, Vietnamese sentence with Japanese, the target highlighted (`target_start`, `target_len`), only for languages in the current target switch and only where a row exists; nothing (no placeholder) otherwise.
5. **音のルール (D71 item 7):** a 「テストする」 button turns the 「このルールの例をすべて見る」 table into a typing test in the same layout: the Vietnamese cell and the Chinese cell become inputs with tone hints, judged by item 1; 「テストをやめる」 returns to the table. Results are not stored (*Claude's reading*: the rule's existing progress `kb_rules` stays the quiz's).
6. **Tests:** judging (tone-only differences right; missing breve/circumflex/horn/đ wrong; Telex letters right; `vi_alt` right; ü/v; case/space/apostrophe); tone hints (neutral, ngang); Space/Enter; mute; deck = 6,983 and no single-character word; card example rendering with/without rows; rule test.

## Part C — Codex: 字体, 偽の友達, 読解

1. **字体 rows (D71 item 1; Claude's design, D75 item 4):** from `glyphs` (SCHEMA §2.1): one row per single-character `card_eligible` word (1,571) + one row per other glyph character (644) = **2,215 rows**, order `level` (empty last), `char_id`, `word_id`. Forms and the ja/ko cells as now (`jp`, `key_char`, `simp`; `ja_on_all`, `ko_base_all`). The pinyin and vi cells show the row's target first, then the character's other `pinyin_all` / `vi_all` readings after 「 / 」 (a glyph-only row's target is the primary, so its display is unchanged; a polyphone such as 還 shows 「hái / huán」 on its hái row and 「huán / hái」 on its huán row). Rows whose three forms are identical appear under すべて (and the level / 間違えた字だけ filters), not under a form-pattern filter. The old multiple-choice クイズ is replaced (item 2); its `kb_glyph` key may be left unused.
2. **字体 typing quiz (D71 item 6):** same list layout; the pinyin cell and the vi cell become inputs for rows whose target is non-empty (`glyphs` gives '' when there is no reading or the Vietnamese reading is `unihan_unverified`: that cell stays plain text, not an input); all inputs open at once; judged on Enter/blur by Part B item 1 (`vi_alt` of the row's word accepted); colours persist in localStorage `kb_glyphquiz` (`{"<row key>": {"zh": 0|1, "vi": 0|1}}`, row key = `word_id` or `char_id`) until re-answered; a score counter (right / answered); filters: the existing ones + **level 1-7** + 「間違えた字だけ」 (rows with a wrong stored answer).
3. **使われ方 panel (D71 item 6):** per row, closed by default (in the quiz it opens after the row is answered); left Chinese, right Vietnamese, from `usage[char_id]`: up to 3 words each. Chinese: `simp` with the character highlighted, pinyin with the syllable at that position highlighted. Vietnamese: `jp` (else `trad`) on the left, `vi` with the syllable highlighted, 「文語」 tag when `lit`. None → 「例なし」. Below: the `char_notes` line when present. A word with `false_friend` ≠ '' gets the small 「偽の友達」 mark, which opens that word's entry in 偽の友達.
4. **偽の友達 list (D71 item 4, option A):** each language line = meaning, then the reading in muted parentheses (「韓 列車（기차）」), all four languages; a fixed-note row (D68) shows its note as now. An opened entry shows one Chinese example (sentence, pinyin, Japanese) and one Vietnamese example (sentence, Japanese) where a row exists: the `ff` row of that word and language, else its `card` row; target highlighted.
5. **偽の友達 flashcards (D71 item 10):** 「フラッシュカード」 next to 一覧, with a 中国語 / ベトナム語 switch (the trap language tested). Pool: entries with a trap in that language. Front: the word and the other languages' meanings with readings (item-4 style). Enter/Space flips: the trap meaning, the reading with a speaker button (respects mute), the example (as item 4). Then 「まだ」 (key 1) / 「わかった」 (key 2); まだ cards return at the end of the round; 20 cards per round; weak words (most まだ, then never seen, then `word_id`) first next round; localStorage `kb_ffcard` (`{"<word_id>:<lang>": {"miss": n, "ok": n}}`).
6. **読解 (D71 item 8):** tapping a linked word marks it 「わからない」 (in addition to opening its detail as now); marked words are listed under the passage for review (same word-detail behaviour on tap); a mark clears when that word is answered correctly in カード (or in the 字体 quiz for a single-character word); a passage is marked read (check mark on its selector pill) the first time it is displayed (*Claude's reading*: the prototype always shows the translation, so there is no "finished" event; the user may ask for a different trigger); localStorage `kb_unknown` (array of `word_id`) and `kb_read` (array of `passage_id`).
7. **Tests:** row counts and order; polyphone display; no input for empty/unverified targets; quiz storage and filters; usage panel (highlight positions, 文語, 例なし, note, ff mark link); ff list format; ff flashcard round logic and storage; 読解 marks and clearing.
