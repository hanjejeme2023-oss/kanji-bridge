# SOURCE PROFILES

Generated by `python pipeline/profile_sources.py` from the files locked in the committed `pipeline/source_manifest.csv` (mirrored at runtime to `raw/MANIFEST.csv`). Raw inputs are never modified. Text is read as explicit UTF-8, trimmed and NFC-normalized for inspection; pandas loads tabular word data with `keep_default_na=False`. Counts below are from the 2026-11-04 download.

The ten-row samples are diagnostic excerpts, not curated facts and not pipeline overrides.
