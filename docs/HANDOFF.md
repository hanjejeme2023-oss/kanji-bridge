### 偽の友達 flashcards

- 「一覧」/「フラッシュカード」 is followed in flashcard mode by the approved 中国語/ベトナム語 trap switch. The front shows the word plus every other available language meaning/readout in Option-A format. Enter or Space flips to the selected trap meaning, reading, mute-aware speaker and preferred/fallback example.
- Each round begins with at most 20 unique entries from the selected trap-language pool. Ordering is lifetime `miss` descending, then never-seen before seen at the same miss count, then `word_id`.
- 「まだ」/key 1 increments `miss` and appends the card to the current round queue; it must later receive 「わかった」. 「わかった」/key 2 increments `ok`. When the queue empties, the next weak-first round is built from current storage.
- Storage is `kb_ffcard`: `{"<word_id>:<lang>": {"miss": n, "ok": n}}`. The global reset clears it.

### 読解 marks, review and ✓

- Tapping any linked word both opens the existing four-language detail and adds its `word_id` to the shared `kb_unknown` array. A deduplicated 「わからない」 review list under the passage reopens the same detail sheet. There is no clear control here: only the existing `clearUnknown(word_id)` calls from a fully correct カード answer or the matching correct 字体 reading remove a mark (apart from the global reset).
- Selecting another passage or switching away from 読解 adds the passage left to `kb_read`, an array of passage IDs. Merely displaying the first passage does not mark it read.
- ✓ is never stored. On every render it appears only when the passage ID is in `kb_read` and none of that passage's linked word IDs is in `kb_unknown`: leave without marks → ✓; marked → no ✓; clear all linked marks → ✓; mark a shared word again from another passage → no ✓.
