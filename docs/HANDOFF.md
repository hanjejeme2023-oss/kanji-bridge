**2. Tasks (PROMPT Stage 4 as completed by D59).** Prompts are written in English, outputs in Japanese. Every prompt says: dictionary facts in the input are given, never change or add a reading; a language whose reading is empty in the input gets no meaning; mark uncertain items `"confidence": "low"` with a short `low_reason`.
- **Task 1, meanings** (8,555 `card_eligible` words; 100 per request, 86 requests, ordered by `word_id`). Input per word: `word_id, trad, simp, jp, ja, ja_alt, ja_common, ko, ko_alt, pinyin, vi, vi_alt, source_vi, pos, level, gloss_en, gloss_ja_en, gloss_ko, gloss_vi`. Output: `{"word_id", "meaning_ja__ja", "meaning_ja__ko", "meaning_ja__zh", "meaning_ja__vi", "meanings_differ", "vi_check", "vi_check_reason", "confidence", "low_reason"}`.
  - Meanings: short Japanese dictionary-style meaning as the word is used **in that language**, using the glosses as the basis. `meaning_ja__ja` only if `ja` is non-empty (a `built_from_chars` `jp` alone does not count); `__ko` only if `ko`; `__zh` only if `pinyin`; `__vi` only if `vi`.
  - `meanings_differ` (bool): the meanings in the languages present differ enough that a learner could be misled. Decides task 2 membership.
  - **`vi_check` (D57 Q1)**, for every word with `vi`: `same_word` / `different_word` / `unsure`; empty when `vi` is empty. `different_word` = the Vietnamese value is a **different Vietnamese word that happens to sound the same**, i.e. written with other Han characters (e.g. 生詞 sinh từ glossed "shrine" = 生祠; 食物 thực vật = 植物). Then `meaning_ja__vi` is empty, `confidence` low, and `vi_check_reason` quotes the gloss evidence. This is **not** the same as a false friend: same characters with a shifted meaning (e.g. 自己 tự kỷ, gloss "autistic") is `same_word` and goes to task 2. The prompt must say: `source_vi=composed_attested` values were composed from character readings and their `gloss_vi` may describe an unrelated word (D51); **`gloss_vi` of a `kaikki_en_han` word is English (D53)**, of other words Vietnamese.
  - `confidence: low` also when the Korean reading looks like a rare or archaic dictionary entry (D49; 小姐 소저, 老公 노공), with `low_reason: "ko_rare"`.
- **Task 2, false friends** (after task 1). Items: every task-1 word with `meanings_differ=true`, **自己 always** (D59), and all 2,504 `ff_candidates.csv` rows (key `form`). 50 per request. Input: the word's forms, readings and glosses (+ task-1 meanings for words). Output: `{"key", "false_friend": ["zh", ...], "meanings": [{"lang", "meaning_ja", "is_trap"}], "confidence", "low_reason"}`. **No reading field in the output**: Codex copies readings from the input tables at merge (SCHEMA §1.4, D16). One `meanings` entry per language whose reading is non-empty; `is_trap` = the language is in `false_friend`. Words with `vi_check=different_word` are not sent with their `vi` (the value is expected to be cleared).
- **Task 3, passages** (after task 1). One request per (language, level): zh and vi × levels 1-7 = 14 requests, **6 passages each** (target ≥ 5 per cell after review). Input: up to 300 linkable words at that level and up to 200 below it (seeded sample, seed recorded), each `word_id`, display form (zh: `simp`, else `trad`; vi: `vi`), `meaning_ja__*` of that language, `level`. Linkable: zh = `pinyin` non-empty; vi = `vi` non-empty, `vi_check=same_word`, not `confidence: low`. Output: `{"passages": [{"translation_ja", "tokens": [...]}]}`, tokens per SCHEMA §1.5. 1-3 sentences, at least 3 linked words, at least one at the cell's level where the list has one; Sino words from the list are linked, not glossed; native/function words get `gloss_ja`; zh text in simplified characters as in the prototype.
- **Task 4, other-reading notes** (D59; user idea 2026-11-05). Input per word: `word_id, trad, ko, vi`, and per differing position: `char`, `lang`, `reading_here`, `primary`, `examples_primary` and `examples_here` (up to 3 other words each, `trad` + that character's reading in it, from `word_chars`; prefer `card_eligible`, then low `level`, then `word_id`).
